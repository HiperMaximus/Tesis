# Plan de Tesis I

Fuente recuperada de `Plan_Maximiliano_2023.zip` y aprobada en Tesis I.

Este directorio es autocontenido y corresponde al futuro proyecto Overleaf
`Tesis I - Plan aprobado`. El contenido académico se considera cerrado. Las
únicas adaptaciones locales son la ubicación ordenada de las figuras, la
detección automática del controlador PDF y la corrección del espacio accidental
en la palabra `redes` del título.

Compilar desde la raíz del repositorio:

```bash
./scripts/document.sh check plan
```
